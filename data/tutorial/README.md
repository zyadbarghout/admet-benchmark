# Synthetic study tutorial data

`study_observations.csv` contains author-created synthetic measurements for
software testing. It has 80 molecular structures, each measured for two
illustrative endpoints. Values are deterministic artificial labels, not
experimental chemistry or ADMET evidence. Endpoint names, units and practical
differences in the example protocol have no scientific interpretation.

The newly authored contents of this CSV are dedicated to the public domain
under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). This statement
applies only to this tutorial CSV, not the repository, existing datasets,
private submissions or historical artifacts.
