# Real cross-validation and uncertainty: research and implementation proposal

Reviewed 2026-09-09. This document records the original research assessment.
The user subsequently authorized implementation. The classical CV/UQ workflow,
chemical diagnostics, saved-fold inference, CV+ pilot and neural smoke adapter
are now implemented; see [implementation guide](../real_cv_uq.md) and
[measured outcome](../real_cv_uq_outcome_2026_09_09.md). Findings below describe
conditions at the time of the assessment, before those changes.

## Recommendation

Connect a versioned study registration to real outer-fold training, produce
out-of-fold predictions and uncertainty on measured KSOL/BBBP data, and feed those
artifacts through the existing evaluator and report. Start with five outer folds;
support ten through the same contract. Begin with classical models to verify the
entire scientific workflow, then use the same assignments for Chemprop/CheMeleon.
Implementation coverage and remaining limitations are recorded in the outcome document above.

## Findings verified in this repository

- `pipeline.py` performs inner CV for hyperparameter search followed by one
  held-out evaluation. `benchmark.py` adds chemistry-aware inner splitters and
  a shared model-selection validation split, but not a complete outer CV runner.
- `study.py` freezes repeated holdouts with one fold per repeat. It does not yet
  register true k-fold partitions or connect assignments to training artifacts.
- Classical model pipelines already fit descriptor imputation and scaling inside
  estimator fitting. That boundary should be preserved in every new fold.
- The evaluator accepts uncertainty scores and intervals, but does not produce
  them. Classification Brier/log loss currently appear in the interactive report,
  rather than the canonical metrics implementation. Prediction sets lack an
  end-to-end schema/evaluation/report path.
- The synthetic demonstration fits real forests on artificial targets. It
  bypasses the production training-registration bridge and cannot validate that
  bridge for measured chemistry.
- Chemprop's existing prediction wrapper calls point prediction only. Both the
  installed uncertainty module and official documentation expose ensemble UQ.
  Integration can reuse that capability rather than invent a neural UQ framework.

### Read-only data audit

`outputs/current_benchmark/{ksol,bbbp_50epoch}/data/`. Development pool means the
union of the previous development and model-selection validation files.

| Duplicate rows beyond the first chemical occurrence | 0 | 53 |

| Bemis–Murcko scaffold groups | 2,281 | 820 |

| Largest scaffold group, rows | 117 | 137 |
| Historical held-out rows | 2,170 | 408 |
| Development-pool / historical-test identity overlap | 0 | 0 |

BBBP development labels comprise 1,243 positive and 388 negative rows before
any duplicate policy. Counts above do not reflect parent/salt/tautomer collapsing;
they use the current canonical isomeric identity policy. Test chemistry was read
for identity auditing, not to choose models or inspect test label quality.

Proposed development policy: retain a traceable representative of same-label
replicates and quarantine conflicting chemical identities pending source review.
That would leave 1,569 unique BBBP development chemicals under the current policy.
Do not apply majority voting, select labels using predictions, or silently delete
original records. Record the policy and all exclusions before freezing folds.
An alternative is explicit replicate modelling; that changes the prediction unit
and requires group-aware calibration. Neither policy has been applied.

The historical tests have already appeared in reports and model comparisons.
Preserve their membership and label them historical held-out evidence. A new
confirmatory claim requires prospective or otherwise genuinely unused data;
renaming an existing test does not make it untouched.

## Proposed CV protocol

1. Freeze identity, duplicate rules, endpoint transforms, dataset hashes, model
   candidates, seeds, split method and UQ level. KSOL remains on its existing
   log10 evaluation scale, applied exactly once. Record original units from the
   source metadata; do not infer assay units from the column name.
2. Save five outer development folds, identical across compared models and
   feature representations. Every eligible chemical has exactly one outer
   validation assignment per repeat. The historical test stays outside CV.
3. Use molecule-grouped random CV as the interpolation reference and scaffold-
   grouped CV as a separate generalization stress experiment. Grouped class
   stratification is approximate: inspect every fold's class and molecule support,
   enforce non-overlapping groups, and fail unsupported protocols instead of
   repeatedly searching seeds for favorable results. Acyclic-scaffold handling
   must be explicit; retain the current common acyclic group unless the protocol
   deliberately adopts another chemistry grouping policy.
4. Inside each outer training pool, reserve approximately 20% for conformal
   calibration. With equal five-fold molecule partitions this is approximately
   64% model fitting, 16% calibration, 20% outer evaluation of development data.
   Scaffold group sizes change those realized proportions; record actual counts.
5. Use fixed, predeclared model settings for the first integration run. When
   tuning is enabled, use inner grouped CV only on the fitting subset. Neural
   early stopping also belongs inside that subset. Neither conformal calibration
   labels nor outer evaluation labels may guide HPO or epoch selection.
6. Save predictions, fold metrics and full role provenance. Add repeated seeds
   after the first complete run; do not call ensemble members CV repeats. Five
   folds with multiple repetitions assess split sensitivity differently from ten
   folds with one repetition. Both use dependent training sets.

Nested CV estimates the selection procedure's generalization more honestly than
using tuning scores as final evaluation. This does not remove uncertainty from
small datasets or make repeated folds independent.
[scikit-learn nested CV example](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html).
Group and stratification behavior should follow the documented semantics and
explicit support audits.
[scikit-learn CV guide](https://scikit-learn.org/stable/modules/cross_validation.html).

## Proposed UQ

### Regression

Use five separately seeded, optionally bootstrapped models of the same family,
fitted within each outer fitting set. Save ensemble mean and member dispersion.
Specify whether the exported score is variance or standard deviation; convert
library outputs explicitly. Five identical deterministic ridge fits would provide
no useful dispersion, so use ridge as a point/constant-conformal baseline or
bootstrap its fitting samples under a declared protocol.

Calibrate two methods for comparison: ordinary split-conformal absolute residuals
and a normalized version using a positive training-defined uncertainty scale.
The normalized method may give molecule-dependent interval widths, but is not
assumed superior. Choose its scale floor without inspecting calibration outcomes.
Use finite-sample corrected quantiles. At insufficient calibration support,
report that a finite interval at the requested coverage is unavailable; never
silently clip the required quantile to a smaller order statistic.

Begin with a predeclared 90% interval, keeping 95% configurable. Assess empirical
coverage, width distribution, interval score, uncertainty/error rank correlation,
and error-retention curves. Distinguish prediction intervals from confidence
intervals on MAE. Construct KSOL intervals on the evaluation scale and transform
both endpoints monotonically for raw-scale display; raw intervals will generally
be asymmetric.

Molecular UQ studies support ensembles as useful baselines, but their results
are dataset/model specific and do not prove that low disagreement means reliable
out-of-domain ADMET predictions.
[Scalia et al., molecular UQ evaluation](https://arxiv.org/abs/1910.03127).

### Classification

Save ensemble mean probabilities, dispersion and a clearly named primary UQ
score. Evaluate discrimination separately from probability quality: PR-AUC,
ROC-AUC, fixed-threshold confusion/MCC, Brier score, log loss and reliability
plots. Retention should include misclassification risk as well as probability
error, with its loss function stated.

Probability calibration and conformal calibration are distinct. Fit sigmoid
calibration using out-of-fold predictions within the fitting pool, or an explicit
additional holdout. If a separate conformal set is then used, it must not have
trained the probability calibrator. Start with a simple, predeclared method;
isotonic calibration can be unreliable with small calibration samples.
[scikit-learn probability calibration](https://scikit-learn.org/stable/modules/calibration.html).

For binary conformal prediction, represent sets explicitly as `{0}`, `{1}`,
`{0,1}` or an empty set. Report set coverage, mean size, singleton rate and
class-specific coverage. Class-conditional calibration is a useful candidate
when each class has enough support. A conformal set is not a confidence interval
around a probability, and should not be forced into `prediction_lower/upper`.

Ordinary split-conformal guarantees require exchangeability between calibration
and evaluation observations. They are marginal, not guarantees for individual
molecules or arbitrary selected chemical cohorts. Scaffold-held-out experiments
can violate those assumptions; measure their coverage empirically and label the
shift, rather than claiming automatic distribution-free coverage there.
[Angelopoulos and Bates tutorial](https://arxiv.org/abs/2107.07511).

### Neural integration

After the classical path is verified, train Chemprop and CheMeleon ensembles on
exactly the registered fitting partitions; prediction must not let the library
make implicit new splits. Reuse checkpoint prediction/UQ support, map its output
semantics into the common artifacts, and test variance versus standard deviation
explicitly. Existing checkpoints fitted on another outer fold's validation or
calibration molecules cannot be reused to claim out-of-fold UQ.
[Chemprop UQ documentation](https://chemprop.readthedocs.io/en/latest/tutorial/cli/predict.html#uncertainty-quantification).

## Concrete delivery sequence and acceptance

| Slice | Deliverable | Required evidence |
| --- | --- | --- |
| Data/protocol | Audited development snapshot and versioned k-fold registration | Duplicate policy recorded; split/hash reproducibility; no group overlap; each molecule evaluated once per repeat |
| Training bridge | Runner that consumes assignments and resumes completed jobs | Fit/calibration/evaluation boundaries tested; exact paired coverage; deterministic seeds; checkpoint and artifact hashes |
| Regression UQ | Ensemble predictions and conformal calibration artifacts | Quantile boundary tests; no refitting on calibration; saved scale/method/nominal level; real KSOL OOF predictions |
| Classification UQ | Calibrated probabilities and prediction-set contract | Disjoint calibration stages; finite probability bounds; correct set membership and metrics; real BBBP OOF predictions |
| Report integration | Real 5-fold report, configurable 10-fold path | OOF identity checks; fold/member distinction; UQ method/coverage provenance; clear missing/unsupported states |
| Neural adapter | Same pipeline for graph/foundation models | Matching assignments; no implicit splits; calibrated outputs traceable to checkpoints |

A first fixed-parameter comparison could use linear, random-forest and extra-
trees baselines with Morgan and RDKit features on both endpoints. With five
members for each tree family this is
`2 endpoints × 2 representations × 5 folds × (1 + 5 + 5) = 220 estimator fits`
per split scheme and repeat, excluding HPO/probability calibration. Ten folds
roughly doubles that count. Profile a single fold first; do not promise a runtime
or launch a full nested neural sweep before measuring cost. This formula counts
forest estimators, not individual trees.

Keep member predictions separate from the canonical ensemble prediction table.
Store conformal calibration artifacts, nominal level, role membership, method,
seed and model hashes. Multiple UQ methods/coverage levels need explicit identity
fields or sidecar tables so the report cannot silently overwrite predictions.
Retain backwards compatibility with existing prepared-prediction imports.

Existing fold distributions and molecule bootstrap intervals remain descriptive.
Do not treat pooled repeated OOF rows as independent molecules or turn fold-wise
p-values into confirmatory inference. Distinguish evaluation of a fixed learner,
a selection procedure, and a final deployment model trained on more data.

## Additional ideas from the original proposal

1. **Chemical applicability and shift panel.** Original Morgan nearest-training-
   neighbour similarity, scaffold novelty, and UQ coverage/error stratified by
   those quantities. This would test reliability in new chemistry more directly
   than treating distances on GTM/t-SNE plots as quantitative. Compute against
   each fold's training reference; the shared display atlas is not that reference.
2. **Threshold-aware decisions.** Given a scientifically chosen property cutoff,
   display whether a regression interval lies entirely above it, below it, or
   crosses it. Keep this property cutoff distinct from the current residual/error
   bands. For classification, show singleton/ambiguous conformal sets and retained
   fraction versus error. Do not derive a probability of exceeding the cutoff
   from a conformal interval alone.
3. **Saved-model prediction for new SMILES.** A local predict command returning
   mean/probability, uncertainty, interval/set, model version and applicability
   evidence, with a batch upload UI later. This is an operational next step once
   final-model refit/calibration semantics and artifacts are verified.
4. **Property-cliff stress analysis.** Inspect highly similar chemicals with large
   measured property differences and evaluate their error/UQ separately. Define
   endpoint-appropriate units and thresholds; do not copy potency-cliff cutoffs
   into solubility. MoleculeACE supplies a relevant primary implementation and
   study to adapt, not a ready-made KSOL scientific protocol.
   [MoleculeACE source and study](https://github.com/molML/MoleculeACE).
5. **CV+ after the simple baseline.** Investigate whether recovering data otherwise
   reserved for calibration improves efficiency. CV+ uses fold-specific residuals
   and predictions; naive averaging of split-conformal intervals is not a
   substitute and does not inherit its theory.
   [Barber et al., jackknife+/CV+](https://arxiv.org/abs/1905.02928).
6. **Resumable local experiment view.** Show planned/running/completed/failed
   endpoint-fold-member jobs, elapsed time and immutable artifact links. This
   would make longer ensembles manageable without adding a cloud dependency.

Do not prioritize more embeddings, MC-dropout/evidential methods, broad neural
architecture searches or hosted deployment before these real-data evaluation
and calibration boundaries are verified. Those can be revisited with measured
baseline shortcomings rather than added speculatively.
