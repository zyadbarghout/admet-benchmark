# BBBP demonstration data

`BBBP.csv` and `clintox.csv` are copied unchanged from the corresponding files in
the `classification data` directory in
[volkamerlab/Zyad_thesis](https://github.com/volkamerlab/Zyad_thesis/tree/main/ADMET_classification),
retrieved for this local benchmark integration on 2026-09-01.

The example configurations use `smiles` as the molecule column, `p_np` for
binary blood-brain-barrier permeability, and `CT_TOX` for ClinTox toxicity.
These copies are included only to make the benchmark suite reproducible. For a
publication or production run, record the source dataset version and its licence
alongside the experiment configuration.
